# Quota And Effort Plan

Fecha: 2026-07-25

## Regla operativa

No se asignan tareas grandes sin objetivo visible, evidencia esperada, archivos/subsistemas afectados, riesgo, dependencias, verificacion y condicion de detencion.

## Acciones para cuidar cuota

- Reutilizar auditoria actual; no pedir a cada agente que vuelva a relevar todo.
- Empezar por Vertical 1, no por "mejorar toda la UX".
- Exigir diff planificado para Backend/Frontend antes de implementar cambios compartidos.
- Mantener contratos como checkpoint separado.
- Usar capturas y E2E como evidencia temprana.
- Bloquear P2/P3 si P0/P1 sigue confuso.

## Estimacion actual

- Agy, correccion de diseño/manifest Vertical 1: media.
- Backend, conciliacion de contratos Vertical 1: baja-media.
- Frontend, ajuste experiencia Vertical 1: media-alta, dependiendo del prototipo.
- Tester, suite candidata: media.
